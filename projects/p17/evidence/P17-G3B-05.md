## Ready plan

- **Accepted plan:** [P17-G3B-05.md](../plans/P17-G3B-05.md), SHA-256
  `407b2dc8e83ccf28d73884db462d7ef9917edde90e3d1729028b12d729b13df2`.
- **Accepted ADR amendment:** [ADR 0007](../../../docs/adr/0007-tool-adapter-registry.md) now
  completes registry-bound lifecycle consumption while preserving the original validated registry,
  cohesive bundle, focused-port, and compatibility decisions. No second adapter or lifecycle
  framework is introduced.
- **Exact scope:** two primary entities, one required-now/impacted selector, no downstream
  coverage, and exactly 55 owned product/test paths: 33 architecture/production/fixture paths and
  22 focused tests. Governance files remain outside the product manifest.
- **Registry boundary:** generic kernels receive the least-authority structural registry projection
  `ids/get/toolsFor/capability`; production wrappers provide the built-in registry once. Derived
  1.x compatibility exports remain, but they are not hidden lifecycle authority.
- **Fixture boundary:** internal lifecycle/planning types retain built-in defaults while private
  generic seams can carry validated fixture IDs through selection, immutable planning, verification,
  placement, hermetic prepared execution binding, and rendering. Fixtures never enter fixed public
  reports, durable swaps, ledgers, journals, artifact codecs, or saved-plan DTOs. Production
  Claude/Codex replays prove durable lifecycle behavior.
- **Placement boundary:** additive root facts plus scope-aware list/resolve methods normalize once
  into a structural superset of the legacy placement bundle. Registry normalization requires one
  destination for every nonempty root set, rejects duplicate paths, preserves old user behavior,
  treats later undeclared roots as alternate, blocks duplicates, and invents no legacy wording.
  Generic lifecycle code no longer interprets root ordinals or rebuilds project/uninstall policy.
- **Verification/rendering boundary:** the existing verification bundle remains authoritative. One

  full model as the default and no cast bridge.
