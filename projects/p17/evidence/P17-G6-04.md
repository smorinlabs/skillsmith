## Mapping result

The mapped architecture is one immutable candidate lineage:

```text
release-please App -> exact tag + draft release
       -> Apple-only GoReleaser signing/notarization candidate
       -> credential-free exact-SHA release-check
       -> GitHub attest/upload/publish
       -> npm OIDC payloads then launcher
       -> reviewed tap cask PR
       -> public EWP-WF01 after tap merge
```

The candidate is never rebuilt, resigned, rearchived, or restaged after validation. Missing and
exact-existing publication state is idempotent; an occupied mismatch fails. No Ready acceptance,
executable selector, test-first receipt, implementation, publication, external mutation, green
result, review GO, traceability closure, or sign-off is claimed by this mapping record.
