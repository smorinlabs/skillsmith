## Implementation-discovered ownership amendment

The bounded foundation and domain passes independently reached the same crash-safety blocker before
accepting a committed-reversal executor. The exact call graph is:

`undo plan -> placement rollback operation -> normal inverse runSwap -> pair compatibility shadow
-> ledger codec cross-reference`.

The logical rollback must retain the original committed forward intent orientation. The normal
inverse swap must instead journal the physical operation that restores that intent's before-image.
The existing codec admits only physical `rollback` for every rollback disposition, so it rejects
that truthful pair. Driving a fresh committed reversal through `rollbackSwap` is also invalid
because it can restore only the backup of an interrupted transaction; it cannot restore retained
state from committed history. The provisional high-level reversal seam was removed before handoff,
and the domain intentionally returns a controlled failure for committed candidates until the
amendment is reviewed and implemented. No unreviewed product path was edited.
