execution flow. It reuses the canonical ledger lock/writer/migration and adds focused GC
inventory/reachability/recovery/repository modules. The strict owner-only recovery temp/CAS protocol

atomically to the absent payload of its exclusively created record-bound action container before
recursive cleanup; the source path is never
