## Ready schema correction

- The mapping section correctly identified the need for a distinct `skipped-after-failure` runtime
  result, but its wording did not yet apply ADR 0008's conservative wire rule. Enum growth is a
  breaking change: flip@3 remains frozen to four outcomes and explicitly refuses the new runtime
  value; current dev/promote JSON advances to flip@4, whose otherwise identical six-field result
  shape admits the fifth outcome. The accepted Ready plan and its independent reviews supersede
  only that wire-version detail. The mapped scheduling semantics and 79/15/64 scope were unchanged
  at this review point; the later Ready trace correction below supersedes those counts.
