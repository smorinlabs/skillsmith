# P17-G1-01 implementation plan

P17-G1-01 establishes one immutable project context, effective-config resolution, shared
tool/scope/capability validation, and bounded target selection. Primary IDs are `EWP-CF-022`,
`EWP-CF-024`, `EWP-CF-031`, `EWP-P1-T01`, `EWP-P1-T02`, `EWP-P1-T03`, `P0-01`, `P0-02`,
`P0-03`, `EWP-OPT-TS06`, `EWP-P1-TS01`, `EWP-P1-TS02`, `EWP-P1-TS03`, and `EWP-WF14`.
Phase 1 entry is passed. G1-01 has no formal dependency; G1-02A is nevertheless signed off first
so this group consumes its shared Commander/error boundary rather than creating another.

Required-now validations are exactly `EWP-OPT-TS06`, `EWP-P1-TS01..03`, and the truthful Phase-1
context/selection slice of `EWP-WF14`. Test first records separate selector failures for `-C` and
cwd/worktree/symlink invariance; operational config precedence and path bases; invalid capability
and same-name cross-scope selection; bounded target/all/zero-match behavior and provenance; and
cross-command project-root identity.

Minimal implementation adds immutable `ProjectContext` values that keep invocation cwd, effective
cwd, canonical live project root, project identity, and discovered/explicit artifact paths distinct.
It adds an effective resolver with CLI > environment > explicit/discovered project > user > system
> built-in precedence and source metadata. Shared typed selection validates tool/scope/capability,
filters scope before resolving name/path/bulk selection, refuses ambiguity or unsafe zero targets,
and records explicit, inferred, path-derived, bulk, or bounded-default provenance. Current
project-aware commands resolve context once and consume G1-02A's output/exit boundary.

Root is integration owner for `program.ts`, current command adapters, options tests, catalog, and
checklist. Core context/config and selection slices may be developed independently, but root alone
integrates their shared exports and command call sites.

Prohibited scope: future status/init/export/plan/apply/sync/update/undo/GC commands; manifest/lock
schemas, ownership, migration, or writes; G1-02B check semantics; G1-02C docs/legacy warnings;
G1-03 CommandSpec/runtime architecture; and G1-04..07 ports, adapter registry, codecs, or observer.
`EWP-WF14` retains its Phase-2/4 artifact-ownership obligations rather than claiming them here.

Mapping amendment (2026-07-12): P0-01's context/parser slice is primary here, while its remaining
output/runtime, observer verbosity/debug, and final TTY/color behavior are explicitly preserved by
`EWP-P1-TS07`, `EWP-P1-TS11`, and `EWP-P6-TS03` downstream. G1-01 must not implement or claim those
later architecture slices.
