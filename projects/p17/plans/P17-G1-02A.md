# P17-G1-02A implementation plan

P17-G1-02A establishes the Phase-1 shared error/output boundary, semantic exit precedence, and
non-mutating-mode policy without pulling the later command runtime or check/doctor semantics
forward. Primary IDs are `P0-06`, `P2-01`, `EWP-P1-T04`, `EWP-P1-T08`, `EWP-CF-004`,
`EWP-CF-043`, `EWP-OPT-TS04`, `EWP-OPT-TS10`, `EWP-P1-TS06`, and `EWP-WF15`. Phase 1 entry is
passed and the group has no dependencies.

Required-now validations are exactly `EWP-OPT-TS04`, `EWP-OPT-TS10`, `EWP-P1-TS06`, and the
Phase-1 slice of `EWP-WF15`. Test first records separate exact-selector failures proving that
current commands accept contradictory approval plus preview modes, unrestricted numeric maximum
lets drift code 7 mask actual errors, output/error behavior is command-local, and public signal
handling is not normalized to the 0..7/130 taxonomy.

Minimal implementation adds a typed exit taxonomy and semantic selector; makes acquire/flip batch
selection delegate to it; adds a normalized human/JSON error boundary; adds a declarative
non-mutating-mode policy validated before discovery, prompts, network, or writes; and normalizes
cancellation to 130. Current command seams are migrated only as needed to prove the contract.
Success JSON bytes remain stable.

Owned implementation files are the new `packages/cli/src/output/error-boundary.ts` and
`packages/cli/src/util/non-mutating-mode.ts`; exit utilities; current config, list, commands,
install, uninstall, dev, promote, check, doctor, and verify adapters; `program.ts` and `index.ts`;
their focused tests; and the four canonical validation targets. Root is the integration owner for
the shared `program.ts` and options-test seams; G1-02A lands before G1-01.

Prohibited scope: G1-01 context/config/selection, G1-02B check/doctor gate semantics, G1-02C docs
and legacy warning, G1-03 CommandSpec/runtime/services, G1-06 codecs, G1-07 observation, and any
future Phase-2+ command. `EWP-WF15` closes only its truthful Phase-1 slice here and retains all
downstream obligations.
