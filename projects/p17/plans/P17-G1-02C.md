# P17-G1-02C implementation plan

P17-G1-02C makes current user-facing help and package documentation describe the live CLI and
preserves exact legacy project-config reads while adding the Phase-2 migration warning boundary.
Primary IDs are `EWP-P1-T06`, `EWP-P1-T07`, `EWP-P1-TS05`, and `P0-05`. Its catalog prerequisites,
G1-01 and G1-02A, are signed off; G1-02B is also signed off before this overlapping integration.

Required-now validation is exactly `EWP-P1-TS05`; the group has no catalogued downstream coverage.
The test-first target will bind the README command/capability/package claims to the live Commander
tree and public package metadata, require runnable current examples, reject internal planning and
research paths from rendered help, and spawn one human legacy-project-config read that proves an
actionable Phase-2 warning and byte identity. The existing G0-04 documentation-drift gate remains an
impacted compatibility check even though it is not a new primary validation.

Implementation has two separable slices after the exact red receipt. The documentation/help slice
updates the root and package READMEs and executable help topics without presenting future commands as
live. The compatibility slice classifies a successfully read discovered project `skillsmith.toml`
as exact legacy metadata and lets human CLI reads emit one warning; parsing, precedence, returned
config values, JSON schemas, and source bytes remain unchanged.

Root owns the plan, catalog, integration, evidence, and final review. A test-first agent owns only
`EWP-P1-TS05`; separate implementers may own docs/help and the legacy notice seam after red is
committed. Shared G0-04, G1-01, G1-02A, and G1-02B files must retain their signed contracts.

Prohibited scope: canonical manifest schema or editor, lossless migration codec, any write or
automatic migration, lock creation, doctor fix, init/apply/plan/migrate commands, G1-03 application
runtime generation, G6 help grouping/completion, and the full WF16 documentation-driven workflow.
